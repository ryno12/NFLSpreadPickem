# 🏈 Spread Pick'em

Private NFL against-the-spread pick'em. DraftKings lines, picks lock at kickoff and stay hidden from the other players until then, one 2-point gold pick per week, running scoreboard, closing-line-value and streak stats.

**Tiebreaker** (from week 8, 2026): predict the final score of the week's last game — Monday night, or Sunday night in a week with no Monday game (week 18). It only matters if the week ends level on points — then the closest predicted **total** wins, and if that's level too, the closest **margin** (home − away, signed, so backing the wrong winner costs double). Anyone who entered a prediction beats anyone who didn't; if neither did, the week stays tied. Predictions lock at that game's kickoff and stay hidden until then, same as picks.

See **SETUP.md** to deploy (Supabase + GitHub Pages + GitHub Actions, all free tiers).
